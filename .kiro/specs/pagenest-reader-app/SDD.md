# Software Design Document (SDD) — PageNest

**Категория:** Читалка сохранённых веб-страниц (аналог Pocket, полностью офлайн)  
**Платформа:** iOS (iPhone + iPad, iOS 16+)  
**Технологии:** React Native (New Architecture), TypeScript, React Native Reanimated 3, React-Native-Skia, React Native WebView, SQLite (FTS5), MMKV, RNFS, Background Tasks  
**Монетизация:** In-App Purchase (one-time «Pro Unlock» + дополнительные пакеты тем/шрифтов)  
**Сеть:** Не требуется (100% офлайн). Сохранение страниц с устройств происходит через Share Extension и/или встроенный браузер-загрузчик, без бэкенда.

## 1) Резюме и цели

PageNest — офлайн-приложение для сохранения и комфортного чтения веб-страниц с полноценным кэшированием текста, изображений, стилей и локальных ресурсов. Приложение предоставляет «режим чтения» (reader mode) с красивой типографикой, быстрым полнотекстовым поиском по библиотеке и мощной офлайн-организацией (теги, коллекции, умные фильтры). Визуальный стиль — минималистичный, «весомый» и тактильный. UX построен на жестах в духе Facebook/Tinkoff: свайпы, перетаскивания, долгие тапы и «pull to…»-жесты.

### Ключевые цели:

- Сохранение веб-страниц с качественной очисткой (Readability) и полным офлайн-кэшем изображений/CSS.
- Reader Mode с индивидуальными темами, шрифтами, размерами, межстрочными интервалами, полями.
- Мгновенный поиск по заголовкам/телу/аннотациям (SQLite FTS5 + индекс).
- Отсутствие бэкенда: все данные и ресурсы — локально. Экспорт/импорт через файлы.
- Гладкие анимации и микровзаимодействия (Reanimated + Skia), включая эффектный анимированный сплэш.
- Жесто-ориентированная навигация: свайпы для архивирования/избранного, «pull to search», pinch-жест для изменения размера шрифта, дрэг-сортировка.

### Не-цели:

- Синхронизация между устройствами (позже как экспорт/импорт через iCloud Drive/Files).
- Онлайн-аналитика, пуш-уведомления, социальные функции.
- Зависимость от сетевых API при чтении.

## 2) Пользовательские сценарии

- Быстро сохранить страницу из Safari через Share Extension, закрыть браузер и прочитать позже офлайн.
- Превратить «шумную» страницу в чистую читабельную разметку, с изображениями внутри и без лишних блоков.
- Каталогизировать: добавлять теги, помещать в коллекции, архивировать, отмечать как избранное.
- Выделять и комментировать фрагменты, быстро находить по ним статьи в будущем.
- Искать мгновенно: по заголовку, тексту, тегам, заметкам, даже при большой библиотеке.
- Менять типографику и темы жестами без захода в настройки.
- Экспортировать библиотеку одним ZIP-файлом (HTML+assets+метаданные) и импортировать обратно.

## 3) Архитектура и стек

### 3.1 Технологии

- **React Native 0.75+** (New Architecture), TypeScript.
- **State:** Zustand (атомарные сторы, сериализация в MMKV при необходимости).
- **Хранилище:**
  - SQLite через react-native-quick-sqlite (+ FTS5 для полнотекстового поиска).
  - MMKV для лёгких KV-настроек и кэшей (последние фильтры, позиции чтения).
  - RNFS (react-native-fs) для структуры файлов: /Documents/PageNest/articles/<id>/index.html, /assets/\*.
- **WebView:** react-native-webview (загрузка из локальных файлов + allowingReadAccessToURL).
- **Парсер/экстрактор:** Mozilla Readability (порт JS) + Cheerio для предобработки DOM.
- **Загрузка ресурсов:** react-native-blob-util / fetch + RNFS, конвейер с очередью и ретраями.
- **Анимации:**
  - Reanimated 3 для переходов/жестов/микровзаимодействий.
  - Skia для сплэша, фона, частиц, масок, шейдеров (например, «жидкий металл», стеклянные осколки).
- **Фоновые задачи:** react-native-background-fetch / react-native-background-actions для докачки при активном экране и «background task» ограниченного времени.
- **Haptics:** react-native-haptic-feedback.
- **IAP:** react-native-iap (StoreKit 2).

### 3.2 Архитектурные слои

- **Domain:** сущности Article, Asset, Tag, Collection, Annotation, ReadingSession.
- **Data:** репозитории (SQLite + файловая система): ArticleRepo, SearchRepo, AssetRepo.
- **Services:** SavePageService, ReadabilityService, DownloadQueue, HtmlRewriter, ExportService, IapService.
- **UI:** экраны/компоненты, коннекторы к сторам Zustand.
- **Animation System:** модуль с переиспользуемыми анимациями (свайпы, пружины, матричные трансформации, скролл-реакции).

## 4) Модель данных

### 4.1 Таблицы (SQLite)

**articles**

- id TEXT PK, title TEXT, url TEXT, domain TEXT, created_at INT, updated_at INT,
- archived INT(0|1), favorite INT(0|1), read_progress REAL 0..1, reading_time INT,
- cover_asset_id TEXT NULL, lang TEXT, word_count INT, has_assets INT(0|1).

**article_content**

- article_id TEXT PK, html_path TEXT, stylesheet_path TEXT NULL, meta_json TEXT (включает исходные метаданные, og:image и т.п.).

**assets**

- id TEXT PK, article_id TEXT, type TEXT ('image', 'css', 'font', 'other'), src_url TEXT,
- local_path TEXT, byte_size INT, mime TEXT, status TEXT ('queued', 'done', 'failed'), hash TEXT.

**tags**

- id TEXT PK, name TEXT UNIQUE, color TEXT.

**article_tags**

- article_id TEXT, tag_id TEXT, PRIMARY KEY(article_id, tag_id).

**collections**

- id TEXT PK, name TEXT UNIQUE, icon TEXT (vector-icon имя), sort_order INT.

**article_collections**

- article_id TEXT, collection_id TEXT, order_in_collection INT,
- PRIMARY KEY(article_id, collection_id).

**annotations**

- id TEXT PK, article_id TEXT, range_json TEXT, text TEXT NULL, created_at INT, color TEXT.

**reading_sessions**

- id TEXT PK, article_id TEXT, started_at INT, last_position_selector TEXT, last_scroll_y REAL.

**fts_articles (FTS5 виртуальная)**

- article_id, title, plain_text, tags_cached, annotations_cached.

### 4.2 Хранение файлов

Директория статьи: `/Documents/PageNest/articles/<articleId>/`

- `index.html` — очищенный HTML после HtmlRewriter.
- `/assets/` — локальные ресурсы (изображения, css, шрифты).
- `meta.json` — вспомогательные данные для быстрой проверки целостности.

## 5) Конвейер сохранения страницы

**Источник:**

- Share Extension (Safari/Chrome: «Поделиться → PageNest»).
- Встроенный мини-браузер (экран «Добавить», для вставки URL и предпросмотра).
- Вставка HTML из буфера (экспертный режим).

**Загрузка HTML:** fetch → HTML-текст (строго по HTTPS; при офлайн вводе возможна загрузка позже).

**Парсинг и очистка:**

- Cheerio: базовая нормализация DOM.
- Mozilla Readability: извлечение content, title, byline.
- Фильтры: удаление скриптов/iframes/трекеров, нормализация ссылок, <noscript>.

**Выделение и планирование ассетов:**

- Сбор src/srcset у <img>, href у <link rel="stylesheet">, @font-face.
- Очередь DownloadQueue со стратегиями ретраев, ограничение параллелизма (e.g. 3 одновременно), прогресс.

**Скачивание и локализация:**

- Таблица assets пополняется.
- Сохранение в /assets/ с sha1-именем и исходным расширением.
- Валидация MIME и размеров; отсеивание >N МБ (настраиваемо).

**Переписывание HTML:**

- Замена URL на file://…/assets/<hash>.<ext> (или относительные ./assets/...).
- Инлайновые стили для базовой типографики Reader Mode, свой CSS настраивается темами.
- Опционально инлайн критического CSS, остальное локально.

**Сохранение:**

- index.html и meta.json пишутся в директорию, запись в article_content.
- Добавление в FTS5: title, plain_text (извлечение текста из content), tags_cached.
- Обновление articles.has_assets = 1.

**Обработка ошибок:**

- Частичные статьи помечаются «незавершёнными», UI предлагает «Догрузить ассеты».
- Фолбэк: если CSS не загрузился, использовать базовый Reader-CSS.

## 6) Reader Engine (локальный рендер)

- WebView загружает index.html из локальной директории статьи c allowingReadAccessToURL на всю папку статьи.
- **Инъекция CSS-тем:** через <style id="pn-theme">…</style> поверх оригинального стиля.
- **Инъекция JS-моста:**
  - Сбор позиций прокрутки и выделений, обработка жестов (pinch для размера шрифта).
  - Команды из React Native: изменить размер шрифта/межстрочное/поля, переключить тему, скролл к аннотации.
- **Изображения:** локальные пути, опционально lqip (низкокачественные прелоады) для плавной заставки.
- **Ссылки:** по тапу — модальный встроенный браузер с опцией «Сохранить как новую статью» или «Открыть в Safari».
- **Table of Contents:** если в тексте есть h2/h3, строится плавающее оглавление (справа на iPad).

## 7) Поиск и индексация

- FTS5 по title, plain_text, кэш тегов/аннотаций.
- Префиксный поиск + подсветка совпадений в результатах.
- История запросов (MMKV).
- **Сортировки:** по дате, домену, длине, чтению, избранному, архиву.
- **Фильтры:** теги, коллекции, «недочитанные», «с аннотациями», «без ассетов», «ошибки загрузки».

## 8) Монетизация (IAP)

**PageNest Pro (разовая покупка):**

- Снятие лимита на количество статей (например, бесплатно до 50).
- Пакет тем (дополнительные 6–8 премиум-тем).
- Доп. шрифты (уровень печати, гарнитуры посадочные).
- Экспорт-импорт всей библиотеки ZIP.
- Пакет «умных фильтров» и сохранённых поисковых запросов.

**Доп. покупки (опционально):** наборы тем/иконпаков.

Реализация через react-native-iap + StoreKit 2, без подписки.

## 9) UX и UI (общие принципы)

- Минимализм, крупная типографика, заметные интерактивные состояния, чёткая иерархия.
- **Тактильность:** лёгкие haptics при ключевых событиях (успешное сохранение, архивирование).
- **Цвет и темы:** Светлая/Тёмная + 4 базовые цветовые палитры, расширено в Pro.
- **Жесты как первичный инструмент:**
  - Свайп карточки влево — Архив (полный свайп) / Доп. меню (короткий).
  - Свайп вправо — Избранное (полный) / Быстрые теги (короткий).
  - Long-press — режим множественного выбора (с анимированным «подпрыгиванием» карточек).
  - «Pull to Search» на списках — раскрывает поле поиска/фильтров.
  - Pinch в Reader — изменяет размер шрифта с пружинной анимацией.
  - Дрэг-энд-дроп на iPad — перетаскивание статьи в коллекции/теги (drag ghost на Skia).

## 10) Экраны и компоненты

### 10.1 Анимированный сплэш (Skia + Reanimated)

**Сцена 1 (0–1.2 c):** Логотип PageNest падает сверху (Reanimated сплайн-траектория с гравитацией), «ударяется», распадается на 24 стеклянных осколка (Skia Particles).

**Сцена 2 (1.2–2.0 c):** Осколки «плавятся» в серебристый «жидкий металл» (Skia шейдер: метаболы/blur blend), собираются в слово PageNest; буквам придают лёгкий twist (матричные 3D-трансформации).

**Сцена 3 (2.0–2.4 c):** Лого «всасывается» в нижнюю кромку, под ним раздвигается Home. Переход — shared element: иконка «гнезда» превращается в FAB «Добавить».

**Хаптика:** мягкий удар при столкновении, лёгкий «success» при сборке текста.

**Технически:**

- Skia Canvas, шейдер на базе окружностей (метаболы) + blur, частицы — массив структур с позициями/скоростями, Reanimated shared values.
- Частицы не превышают 60 fps, ограничение количества и простая физика (гравитация + затухание).

### 10.2 Онбординг (3 экрана, свайпами)

- «Сохраняйте страницы офлайн» — карточка с демо-анимацией (мини-браузер → чек «Saved»).
- «Красивый reader-режим» — показ тем/шрифтов (Skia маски для смены темы).
- «Жесты ускоряют всё» — интерактивный тренажёр свайпов на карточке.

**Компоненты:** OnboardingCarousel, FeatureCard, GestureTrainer.

**CTA:** Продолжить → запрос разрешения на Share Extension «Как добавить PageNest в меню Поделиться» (пошаговая инструкция с скриншотами).

### 10.3 Home / Library

**Структура:**

- **AppBar:** заголовок «PageNest», кнопка «Поиск» (лупа), иконка «Фильтры», профиль/IAP.
- **Smart Tabs (segmented control):** «Все», «Избранное», «Архив», «Недочитанные», «С ошибками». Переключение с пружинной underline-анимацией (Skia).
- **Список карточек (FlashList/RecyclerListView):**
  - Карточка: фавикон/домен, заголовок, превью (cover), теги (до 3), индикатор прогресса, время чтения.
  - **Свайпы:**
    - Влево: раскрытие фона с иконкой «Архив», при полном свайпе — архивирование (фон заполняется градиентом, иконка масштабируется, haptic «success»).
    - Вправо: «Избранное» (иконка звезды) или «Быстрые теги» (короткий свайп открывает горизонтальный чип-пикер).
  - Long-press: переход в «Multi-Select Mode» (чекбоксы появляются с scale-анимацией), нижняя панель действий.
- **FAB «+»** (shared element из сплэша): раскрывающийся Speed Dial: «Вставить URL», «Открыть мини-браузер», «Импорт ZIP».
- **Pull to Search:** при перетягивании списка вниз AppBar трансформируется в строку поиска (stretch-анимация), placeholder → активное поле.

**Состояния:**

- Пустая библиотека — показ «первого шага» с крупной кнопкой «Добавить».
- Ошибки загрузки — подсветка красным чипом «Незавершённые», карточки с кнопкой «Догрузить».

### 10.4 Экран «Добавить»

- Поле URL (автоматическая валидация), кнопка «Загрузить», прогресс-бар очереди.
- Мини-браузер-предпросмотр: WebView с упрощённой шапкой и кнопкой «Сохранить как Reader».
- Переключатель «Сохранять изображения/CSS/шрифты» (по умолчанию включено).
- Кнопка «Теги…» (sheet с чипами и быстрым созданием нового тега).
- После сохранения — баннер успеха с опцией «Открыть»/«Назначить коллекцию».

**Анимации:** sheet выезжает снизу, поля «пульсируют» при ошибке, прогресс-бар — градиентный shimmer.

### 10.5 Reader

- **AppBar (авто-hide при скролле вниз):** Назад, Заголовок (marquee при длинных), Меню (шрифт/тема/экспорт).
- **Контент:** локальный WebView с темизацией.
- **Toolbar жестов (полупрозрачная лента снизу, скрывается):**
  - Размер шрифта (– / +) — также pinch изменяет.
  - Межстрочное и поля (stepper).
  - Переключатель темы (иконки превью).
- **Notes/Highlights:** выделение текста long-press → всплывающее меню «Выделить», «Заметка», «Копировать». Выделения подсвечены цветом темы; тап — показывает заметку.
- **TOC:** кнопка «Оглавление» — боковой слайд-овер со списком подзаголовков (скролл до якоря).
- **Прогресс:** тонкая полоса прогресса чтения сверху (Skia path, реагирует на скролл).

**Анимации:**

- Появление AppBar/Toolbar на скролле вверх (spring).
- Цветовые переходы тема↔тема через Skia-mask fade.
- Смена размера шрифта — контент масштабируется с упругостью, после отпускания перерисовка без «скачков».

### 10.6 Search & Filters

- Поле поиска c подсказками (история запросов, популярные теги/домены).
- Результаты списком с подсветкой хит-фрагментов из FTS5 (отрисовка выделений через TextWithHighlights).
- **Фильтры:** теги (чипы), коллекции (иконки), время чтения, статус (избранное/архив/ошибка).
- **Сохранение запроса (Pro):** даёт быстрый таб на Home (появляется новый Smart Tab).

**Жесты:**

- Свайп влево по «сохранённому запросу» — удалить.
- Долгий тап — переименовать (sheet).

### 10.7 Collections & Tags

- Grid/список коллекций с иконками (vector-icons, например Material Community Icons).
- Внутри коллекции — список статей, поддержка drag-sort (iPad), reorder фиксируется в article_collections.order_in_collection.
- Экран «Все теги» — облако тегов, сортировка по частоте, быстрый фильтр.

### 10.8 Bulk Actions (Multi-Select)

- Активируется long-press на карточке или кнопкой «Выбрать».
- Нижняя панель: Добавить теги, В коллекцию, Архив, Удалить, Экспорт.
- Выделенные карточки чуть «подпрыгивают» при отметке (scale 0.95 → 1.0).
- Подтверждение удаления — шторка с предупреждением.

### 10.9 Settings

- **Аккаунт/IAP:** статус Pro, восстановить покупки.
- **Reader Defaults:** тема по умолчанию, шрифты, межстрочное, поля, включение «очищать до reader всегда».
- **Загрузка:** лимит параллельных загрузок, лимит размера изображений, «докачивать при Wi-Fi только».
- **Хранилище:** обзор занимаемого места, очистка кэша «битых» ассетов, переиндексация FTS5.
- **Экспорт/Импорт:** создать ZIP, импортировать ZIP (с валидацией).
- **О приложении:** лицензии зависимостей (Readability и др.).
- **Приватность:** никакой телеметрии/отправки данных.

## 11) Жесты — карта по приложению

**Списки:**

- Свайп L/R — архив/избранное/быстрые теги (с адаптивными порогами).
- Pull-to-search — раскрытие поиска вместо «pull to refresh».
- Long-press — Multi-Select.

**Reader:**

- Pinch — размер шрифта.
- Двойной тап — центрировать следующий абзац, либо «быстрый +1 размер».
- Панель жестов снизу — свайп вниз скрыть.

**Коллекции/Теги:**

- iPad drag-and-drop.

**Диалоги/шторки:**

- Свайп вниз — закрыть.

## 12) Анимации и микровзаимодействия (детали реализации)

- **Свайпы карточек (Reanimated):**
  - PanGestureHandler + useAnimatedStyle для смещения по X, фоновая Skia-подложка окрашивается в зависимости от прогресса.
  - Пороговые значения (например, 25% ширины — короткий свайп, 60% — полный).
  - По отпусканию: spring к исходному/вне экрана с withTiming/withSpring.
- **Shared Elements** между списком и Reader (изображение/заголовок).
- **Shimmer-прогресс (Skia):** маска градиента поверх прямоугольника.
- **Highlight анимации:** при создании выделения — короткая вспышка под текстом.
- **Темы:** переходы через промежуточные шейдер-фейды (Skia).
- **Прокрутка Reader:** «индикатор прогресса» как path с ease-анимацией.

## 13) Мини-браузер и Share Extension

- **Share Extension (native часть + RN bridge):** принимает URL/HTML и очередь на сохранение. UI мини-формы: добавить теги/коллекцию/заметку.
- **Встроенный браузер (экран «Добавить»):** простая WebView с кнопками «Назад/Вперёд/Обновить», кнопка «Сохранить Reader».
- **Политики безопасности:** без выполнения сторонних скриптов в сохранённом контенте; все <script> вырезаются.

## 14) Экспорт/Импорт

**Экспорт ZIP:**

- Структура: /articles/<id>/\* + db.sqlite (или dump), manifest.json (версии схем, список статей).
- Пользователь выбирает: всё или выбранные, включая/исключая assets (для облегчения).

**Импорт ZIP:**

- Валидация версии, дедупликация по url+title+hash.
- Конфликты — диалог «объединить/заменить/пропустить».

## 15) Производительность

- Списки: FlashList/RecyclerListView для больших библиотек.
- FTS5 индексы и инкрементальная переиндексация при изменениях.
- Ограничение ассетов на статью и глобальное, авто-очистка «сиротских» файлов.
- Memo/Windowing в React, отсутствие тяжёлых ререндеров.
- Throttling событий скролла/жестов.

## 16) Безопасность и приватность

- Все данные локально.
- Нет трекинга/аналитики/сетевых SDK.
- **Опциональное шифрование библиотеки (Pro):**
  - Метаданные в SQLite остаются открытыми для FTS5; содержимое HTML и ассеты могут храниться незашифрованно (ради производительности) или шифроваться выборочно (архив).
  - Ключ в iOS Keychain; переключение шифрования требует миграции (блокирующая операция с индикатором).

## 19) Качество, тестирование, отладка

**Юнит-тесты:** парсер/переписыватель HTML, DownloadQueue, SearchRepo.

**Снимочные тесты UI** (скелеты списков).

**Бенчмарки:**

- Время сохранения средней статьи (< N сек локально, без сети после загрузки).
- Потребление диска на 1000 статей (ограничения и авто-очистка).

**Edge cases:** страницы без <article>, heavy-JS сайты, очень большие изображения, страницы с lazy-loading (подмена data-src), редиректы 301/302, svg-изображения, нестандартные шрифты.

**Инструменты отладки:** экран «Debug» (только Dev): просмотр состояния очереди загрузок, принудительная переиндексация, тест анимаций сплэша.

## 20) Риски и смягчение

- **Ограничения WKWebView с локальными файлами** → загружать index.html через source={{ uri: file://… }} и выставлять allowingReadAccessToURL на папку статьи; все ассеты — относительные пути.
- **Очень тяжёлые страницы** → лимиты на размер и количество ассетов, опция «только текст».
- **Совместимость FTS5** → проверка поставляемой SQLite, fallback на LIKE-поиск при крайне старых сборках (iOS 16+ — ок).
- **Share Extension сложность** → строгая оптимизация времени выполнения расширения, вынос тяжёлых операций (загрузка ассетов) в основное приложение при открытии.

## 21) Детализация компонентов (ключевые)

**SavePageService:**

- saveFromUrl(url, options): Promise<ArticleId>;
- шаги: скачивание→парсинг→очередь ассетов→переписка HTML→сохранение→индексация.

**DownloadQueue:**

- очередь на RNFS-загрузки с параллелизмом, ретраями (экспоненциальная пауза), прогресс-стримом в Zustand.

**HtmlRewriter:**

- заменяет href/src/srcset на относительные пути, удаляет скрипты, инлайнит критический CSS, вставляет наш <script> bridge.

**SearchRepo:**

- search(query, filters, sort): Promise<Result[]> с FTS5 и подсветкой.

**ThemeEngine:**

- объект темы (цвета/шрифты/размеры), генерит CSS-фрагмент и отдаёт в WebView (replace содержимого <style id="pn-theme">).

## 28) Примечания по реализуемости «только RN+JS»

Все описанные ключевые функции реализуемы на RN+JS:

- Парсинг/Readability — JS.
- Переписывание HTML — JS.
- Загрузка и файлы — RNFS/Blob-util (native под капотом, но стандартный RN-модуль).
- WebView — стандартный RN-модуль.
- FTS5 — через RN SQLite (native driver, управление из JS).
- Share Extension — потребует нативного расширения, но подключается типовым RN-модулем, логика остаётся JS.
- Анимации — Reanimated/Skia (JS API с бриджем/новой архитектурой).

## Итог

PageNest — производительное, приватное и полностью офлайн-решение для сохранения и чтения веб-страниц с красивой типографикой, мощным поиском и «жестовой» философией интерфейса. Реализация опирается на зрелые RN-модули, анимации уровня нативных приложений (Reanimated + Skia) и надёжный файлово-базовый стек (SQLite/FTS5 + RNFS). Монетизация через Pro-разблокировку даёт прозрачную ценность без подписок: неограниченную библиотеку, расширенные темы/шрифты и экспорт/импорт.
